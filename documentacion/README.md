## Resumen del producto

PlanUp es una PWA para que un entrenador asigne a cada atleta una sesión de entrenamiento en una fecha concreta. El entrenador escribe texto libre y el atleta consulta su programación desde el celular.

El MVP evita deliberadamente pagos, chat, videos, estadísticas, leaderboards, gestión de gimnasios y programación estructurada por ejercicios. El objetivo inicial es validar el flujo mínimo entrenador–atleta con un costo de infraestructura menor a USD 5 mensuales.
